This is a fork of [MartiGeek17](https://github.com/MartiGeek17/LoRa-RFM95-STM32). The changes made are the bare minimum I had to do to get MartiGeek17s RF95 library working on my STM32 Nucleo L476RG with a SX1276 LoRa module.

# LoRa-RFM95-STM32
This repository contains the different versions of a library to be used in STM32 devices for the devices RFM95/96/97/98. It can be adapted to other microcontrollers changing the communication orders.
